# PIMDA

Code and experiments for PIMDA: a model of host + PIM performance, agents that add design options, and gates that verify them. The case study is a coding agent (mini-swe-agent + mini-coder-4b on SWE-bench Verified) against an RTX 3080.

- `build-plan.md`: the plan. Start here.
- `AGENTS.md`: working rules.
- `data/`: inputs. Never edited.
- `library/`: the numbers and options, with their sources. PDFs go in `library/sources/`.
- `old/`: the previous version (the Domeline harness), kept as a reference. Its own README is `old/README.md`. To run it, check out the branch `autopilot`.
